FFmpeg 9.0.1 (essentials build by gyan.dev)
https://ffmpeg.org/   https://www.gyan.dev/ffmpeg/builds/

CompressionRecorder.exe contains an unmodified FFmpeg executable (compressed) and
runs it as a separate program to record and encode video. This build includes GPL
components (libx264 and others), so FFmpeg is licensed under the GNU General Public
License version 3 (see FFMPEG_LICENSE.txt). Corresponding source code:
https://ffmpeg.org/releases/ffmpeg-9.0.1.tar.xz
The FFmpeg build is not modified; the application code is a separate program that
only starts ffmpeg.exe as an external process.
